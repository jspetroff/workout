Privacy Policy

Project Petroff Workout Tracker — Last updated May 2026

This application is a personal fitness tracking tool built and used solely by John Petroff. No data is shared with third parties, sold, or used for any commercial purpose.

Data Collected

Heart rate variability, workout sessions, recovery metrics, and personal notes entered by the user.

Data Storage

All data is stored in Firebase Firestore under the user's personal account. Whoop biometric data is accessed via the Whoop API using OAuth 2.0 and is not stored permanently — only the daily HRV value is retained for trend tracking.

Third-Party Services

This app uses the following third-party services, each governed by their own privacy policies:

Anthropic API — workout recommendations and HR chart analysis

Firebase (Google) — data storage

Whoop API — HRV and recovery data

Data Security

API keys and credentials are stored server-side in Firebase Cloud Functions and are never exposed to the client.
